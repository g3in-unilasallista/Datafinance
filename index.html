📌 Contexto

Planteamiento del Problema

En el contexto financiero actual, los inversores particulares y corporativos necesitan herramientas accesibles que les permitan analizar el comportamiento histórico de acciones bursátiles de manera visual, rápida y confiable.

Las plataformas de análisis profesional como Bloomberg Terminal o Reuters Eikon tienen un costo prohibitivo. Python y el ecosistema open-source ofrecen una alternativa de calidad profesional de forma gratuita.

Este proyecto demuestra cómo un analista de datos puede construir en pocas horas una herramienta completa que antes requería meses de desarrollo y presupuestos elevados.

🎯 Metodología

Objetivos SMART

Cada objetivo fue diseñado siguiendo el marco SMART para asegurar claridad, medibilidad y viabilidad del proyecto.

S

Específico (Specific)

Analizar los precios de cierre históricos de AAPL, MSFT y NVDA durante el período 2025–2026 usando Python, Pandas y Plotly, consumiendo datos desde precios_acciones.csv.

M

Medible (Measurable)

Generar 3 visualizaciones interactivas clave: cotización histórica, simulación de $1,000 USD y precio promedio, con métricas estadísticas cuantificables (media, correlación, box plots).

A

Alcanzable (Achievable)

Construir una app web funcional con Streamlit, desplegada en Streamlit Cloud, con repositorio público en GitHub, consumiendo el CSV local sin dependencias externas de red en tiempo de ejecución.

R

Relevante (Relevant)

Aplica competencias del semillero (Python, pandas, plotly, IA generativa) para resolver una necesidad real del sector financiero, alineado con los objetivos del Semillero de Datos & Tecnología de la UFHEC.

T

Temporal (Time-bound)

El análisis cubre exactamente 252 días hábiles (septiembre 2025 – septiembre 2026), con todos los entregables completados en el segundo semestre académico 2026.

🚀 Inicio Rápido

Cómo Ejecutar

La aplicación se puede ejecutar localmente en 4 pasos. Requiere Python 3.11+.

📟 Terminal — PowerShell / CMD / Bash 
# 1. Clonar el repositorio desde GitHub
git clone https://github.com/feibert-ufhec/analisis-financiero-python.git
cd analisis-financiero-python

# 2. Crear y activar entorno virtual (recomendado)
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

# 3. Instalar dependencias
pip install -r requirements.txt

# 4. Ejecutar la aplicación
streamlit run app.py

# ✅ La app se abre en: http://localhost:8501
☁️ Despliegue en Streamlit Cloud

1. Sube el repositorio a GitHub
2. Ve a share.streamlit.io
3. Selecciona el repo → app.py
4. Haz clic en Deploy ✅
